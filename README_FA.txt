ربات Adnan VPN - نسخه اولیه

منوی ربات:
- 🚀 خرید کانفیگ
- 🧪 اکانت تست
- 📞 پشتیبانی
- 🎁 معرفی به دوستان

/start پیام خوش‌آمدگویی را برای هر کاربر می‌فرستد.
درخواست خرید، تست و پشتیبانی به مدیر ارسال می‌شود تا کانفیگ را دستی بفرستد.

نکته مهم:
این فایل به‌تنهایی ربات را روشن نمی‌کند. باید روی یک سرویس میزبانیِ پشتیبان Python اجرا شود.
GitHub فقط محل نگهداری کد است و خودش ربات را اجرا نمی‌کند.

تنظیمات لازم در سرویس میزبانی:
BOT_TOKEN = توکن ربات از BotFather
ADMIN_CHAT_ID = شناسه عددی تلگرام مدیر

توکن ربات را در GitHub عمومی یا برای دیگران نفرست.
برای پیدا کردن ADMIN_CHAT_ID می‌توانی از یک ربات معتبرِ نمایش شناسه تلگرام استفاده کنی.
